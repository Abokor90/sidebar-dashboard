# 💻 DevSpace Dashboard

DevSpace is a responsive developer portfolio dashboard built from scratch using **HTML, CSS, and JavaScript**.

It uses a sidebar navigation system that allows users to move between different sections of the dashboard without loading separate pages.

## 🚀 Features

- Responsive sidebar navigation
- Desktop sidebar collapse/expand
- Mobile hamburger menu
- Mobile menu close button
- Section-based navigation
- Home section
- About section
- Projects section
- Skills section
- Blog section
- Contact section
- Skill progress bars
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Boxicons
